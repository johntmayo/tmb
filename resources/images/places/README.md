Use landscape images when possible. From Wikimedia Commons, choose **1,280 × 960**; it is sharp enough for high-density phones without bloating the offline app.

## Attribution still needed

For every Wikimedia image above, provide its source URL, creator, and license. These details are required for `PHOTO-CREDITS.md`; uploading the image alone does not preserve them.
